- 统一 `run_pi.sh` → `run_pi.py`；single 默认监测，split 分别保存 prepare/reproduce 会话和交接。Actual #8351 脚本已升级，原业务修改和复现测试的内容摘要核对未变。

- 原始 JSONL 为唯一用量来源；重复条目去重、压缩/分支/独立 usage 合计、截断/缺失/版本问题标未知。原始事件不再重复计费。支持重算、single/split 汇总与 pair-id 对照，验收字段独立。
- `python3 -m unittest discover -s script_tool/make_bug/test -q`：96 项通过；Python 编译、README 17 段 Bash 语法、diff 空白检查通过。新增监测测试全部用假 Pi，无付费调用。
- 已找到本机 `/home/elexcfe/.local/lib/node-v24/bin/pi`（1.0.4），初次未找到是当前 PATH 未包含该目录。最小真实调用与会话解析已通过；完整复现及交互终端端到端验收未运行。解析以 v3 格式为准；费用为估算，限额为软限制。目录隔离不是访问控制；热环境自动克隆、容器沙箱、语义自动标注和正式实验仍未实施。复制/归档不是硬实时中断，实际总耗时如实保存。
