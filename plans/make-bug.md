## 技术决定

- Python 标准库实现，依赖 Git、GitHub CLI；pi 只在启动复现时需要。
- 自动版本取唯一已合并关闭 PR 的合并提交第一父提交；这只是候选基线，不保证 Bug 已存在。用户可用 --ref 或 --fix-pr 覆盖。
- Git archive 导出代码，不切换已有工作区，不给复现 Agent 提供历史答案。
- Issue 原文保留，不抓评论；不能保证原文没有修复线索，启动前可审阅。
- 生成阶段不执行依赖安装；按后续用户要求，启动 pi 前自动复用或安装依赖。不承诺网络隔离，允许环境下载，禁止网络搜索和查阅修复答案。
